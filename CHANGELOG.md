# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0]

### Added
- Interactive TUI table to inspect all installed tools, sources (built-in, SDK, npm, local extension), and descriptions.
- Instant search and filtering by tool name, source, or description.
- Tool detail view with full parameter documentation, types, and schema inspection.
- Enable / disable toggle with persistent configuration in `~/.pi/agent/tools-manager.json`.
- Slash command `/tools [name]` with argument autocomplete.
- Non-TUI fallback output for print and non-interactive environments.
